# Guía de Zorblat

Zorblat es un lenguaje de programación ficticio creado en 2031 por la doctora Ilaria Venkman.

## Características

- Su mascota oficial es un pulpo llamado Pulpito.
- Los comentarios se escriben con el símbolo `~~`.
- La palabra clave para declarar variables es `quibble`.

---

## Instalación

Para instalar Zorblat se ejecuta el comando `zorb install` y se reinicia la terminal.
